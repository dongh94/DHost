# 정책 결정 기록

PRD의 미결정 항목(OPEN-xx) 중 정한 것을 기록한다. 바꿀 때는 날짜와 이유를 남긴다.

## 2026-11-06

### OPEN-02 비밀번호 저장 → macOS 키체인에 선택 저장
- 비밀번호 창에서 "키체인에 저장"을 체크했을 때만 저장한다. 서버 프로필 하나당 하나 (`server:<프로필 ID>`).
- DB·설정 백업에는 넣지 않는다 (POL-05, SEC-04).
- 자동 입력은 구간마다 첫 질문에만 한다. 틀리면 저장된 값을 지우고 사람에게 묻는다.
- 새로 저장한 비밀번호가 틀리면(다시 묻거나 30초 안에 ssh 오류로 끝나면) 저장하지 않은 것으로 되돌린다.
- 빠른 접속(프로필 없음)은 저장하지 않는다.
- 서버를 지우거나 호스트·포트·사용자를 바꾸면 저장된 비밀번호를 지운다 (SEC-P03, GAP-02).
- 앱 잠금(Touch ID)은 v1.x에서 검토한다.

### 비밀번호 창의 취소 동작
- **취소 = 그 접속 시도를 끝내고 창만 닫는다.** ssh가 비밀번호를 다시 묻지 않는다.
- 확인을 눌렀는데 비밀번호가 틀리면 ssh 기본값대로 최대 3번까지 다시 묻는다.

### OPEN-01 기존 SSH 설정
- `~/.ssh/known_hosts`: 계속 함께 읽지 않는다. 호스트 키 화면에서 **사용자가 고른 항목만 가져온다.** 해시된 항목·와일드카드·@cert-authority는 가져오지 않는다.
- `~/.ssh/config`: 지금처럼 적용하되 보안 옵션(호스트 키 검증, ControlMaster, ProxyJump 등)은 DHost가 정한다.
  - 서버 편집 화면의 "실제 적용값 보기"로 `ssh -G` 결과를 보여준다 (SEC-P02). DHost가 정한 값은 따로 표시한다.
  - 서버 목록의 "가져오기"로 Host 항목을 서버 프로필로 가져온다. 한 단계 ProxyJump는 경유 서버로 연결하고, 여러 단계는 경유 없이 가져온다. 같은 주소·포트·사용자가 이미 있으면 건너뛴다.
- 두 파일 모두 읽기만 하고 고치지 않는다.

### OPEN-03 접속 이력 → 30일 보관
- 서버, 대상, 경유, 시작·종료 시각, 결과, 종료 코드만 기록한다. **명령·출력·비밀번호는 기록하지 않는다** (SEC-P04).
- 결과: 정상 종료 / 인증 실패 / 호스트 키 거절 / 키 변경 차단 / 취소 / 연결 오류 / 앱 종료로 중단
- 결과 분류는 ssh 종료 코드와 DHost 이벤트로 판단하므로 대략적이다 (예: 인증 실패와 네트워크 오류 구분).
- 앱을 시작할 때 30일 지난 기록을 지운다. 백업에서 제외할 예정이다.

### 백업·복원 (POL-05, FUN-12)
- 형식: JSON 파일 `.dhost-backup` (권한 0600). 고객사·폴더·서버 프로필, 설정, 선택 시 신뢰한 호스트 키(공개키)
- 넣지 않는 것: 비밀번호(키체인), 개인키, 접속 이력
- 복원 방식: **합치기**(기본, 같은 주소·포트·사용자 서버는 건너뜀, 같은 이름 고객사·폴더는 합침) / **전체 교체**(기존 목록과 저장된 비밀번호 삭제)
- 복원 파일은 신뢰하지 않는다: 형식·버전·크기(10MB)·주소(옵션 주입)·참조·단일 경유·지문·설정 값을 다시 검사하고, 문제 항목은 건너뛴다.
- 이미 다른 키를 신뢰하는 호스트의 키는 덮어쓰지 않는다.
- 한 트랜잭션으로 처리하고, 복원해도 자동 접속하지 않는다.

### 배포 범위
- 팀 내부 전용. Apple 코드 서명·공증은 하지 않는다 (2026-11-06).

### 오류 진단 (FUN-16)
- ssh가 오류(종료 코드 255)로 끝나면 마지막 출력 8KB를 메모리에서만 보고 원인을 고른다. 출력은 저장하지 않고 진단 후 버린다 (SEC-P04). 접속 이력에는 원인 코드만 남긴다.
- 원인: 주소 없음 / 연결 거부 / 시간 초과 / 네트워크 없음 / 서버가 끊음 / SSH 아님 / 비밀번호 틀림 / 키 전용 서버 / 시도 횟수 초과 / 보안 방식 불일치 / 경유 차단 / 경유 후 연결 실패 / 연결 끊김 / 호스트 키 거절·변경
- 경유 접속은 메시지 속 호스트로 실패한 구간(경유 서버 / 대상 서버)을 표시한다.
- 사용자가 인증을 취소하거나 탭을 닫은 경우는 오류로 보지 않는다.
- 한계: 원격 셸 출력에 ssh 메시지와 같은 문구가 섞이면 틀릴 수 있다. ssh 메시지 형식에 맞는 줄만, 마지막 줄부터 본다.
- 연결 시간 제한(ConnectTimeout) 기본 15초, 설정에서 5~120초. 경유 서버 구간에도 같은 값을 쓴다.

### 단축키 (GAP-06)
- macOS 메뉴 막대 **세션** 메뉴에 단축키를 건다. 메뉴에서 단축키를 찾아볼 수 있고, 터미널에 포커스가 있어도 동작한다.
- ⌘K·⌘T 서버 검색(↑↓ 선택, Enter 접속) / ⌘W 탭 닫기 / ⌘R 끊긴 탭 재접속 / ⌘1~8 n번째 탭, ⌘9 마지막 탭 / ⌘⇧] ⌘⇧[ 다음·이전 탭 / ⌘, 설정
- 기본 메뉴의 "윈도우 닫기(⌘W)"는 뺐다. ⌘W는 앱 창이 아니라 세션 탭을 닫는다.
- 연결된 탭을 ⌘W로 닫으면 한 번 묻는다. 끊긴 탭은 바로 닫는다. 탭의 X 버튼은 묻지 않는다.
- 확인 창이 떠 있을 때는 단축키가 뒤의 화면을 건드리지 않는다.

### 대량 출력 (GAP-05)
- 화면(xterm)의 처리 대기량이 512KB를 넘으면 PTY 읽기를 멈추고, 64KB 아래로 내려가면 다시 읽는다. 읽기를 멈추면 ssh와 원격 서버도 TCP 흐름 제어로 기다린다.
- 멈춘 동안에도 입력은 보내므로 Ctrl+C로 바로 멈출 수 있다 (E2E로 확인).
- 탭마다 스크롤 보관 줄 수가 메모리 상한이다. 기본 5,000줄, 설정에서 1,000~50,000줄.

### 원격 출력의 링크·제어 시퀀스 (GAP-04)
- 원격 서버 출력은 믿지 않는다. 링크는 **⌘+클릭**일 때만 반응하고, 그냥 클릭은 글자 선택에 쓴다.
- 열기 전에 확인 창에서 실제 사이트(호스트)와 전체 주소를 보여 준다. 기본 선택은 취소다. http·https만 허용한다(javascript:, file: 등 거부). 앱 권한도 http·https 주소 열기만 허용한다.
- OSC 8 링크에서 화면에 보이는 주소와 실제 주소의 사이트가 다르면 빨간 경고를 띄운다.
- 창 조작·보고 요청(CSI t), 클립보드 쓰기(OSC 52)는 지원하지 않는다. 원격이 바꾼 창 제목도 쓰지 않는다.
- 바이너리 출력 등으로 화면이 깨지면 **화면 초기화**로 터미널 상태만 되돌린다. 연결은 유지된다.

### 배포 준비
- **최소 macOS 12 Monterey.** DHost는 시스템 `/usr/bin/ssh`의 `KnownHostsCommand`·`SSH_ASKPASS_REQUIRE`(OpenSSH 8.5+)에 기대는데, macOS 12가 OpenSSH 8.6을 기본 탑재한 첫 버전이다. 11 Big Sur는 8.1이라 지원하지 않는다.
- **Apple Silicon 전용 .dmg**(aarch64). M2 우선 요구에 맞춘다. Intel 빌드는 요청이 있으면 universal로 추가한다.
- **ad-hoc 서명**(`signingIdentity: "-"`). 인증서·공증 없음. 처음 열 때 Gatekeeper 허용 안내를 [install.md](install.md)에 둔다. 버전이 바뀌면 키체인 접근 확인 창이 다시 뜰 수 있다.
- **CI**: 비밀 정보 검사(자체 스크립트 + gitleaks), macOS에서 테스트·clippy·형식 검사, cargo/pnpm audit. Docker E2E는 배포 전 로컬에서 돌린다.
- **배포**: `v*` 태그를 올리면 .dmg와 SHA256 체크섬을 초안 Release로 올린다. 관리자가 확인 후 공개한다.
- Rust 코드 형식은 rustfmt(`max_width = 120`)로 통일하고 CI에서 검사한다.
