# DHost 설치 안내 (팀 내부)

DHost는 팀 안에서만 쓰는 앱이라 Apple 개발자 인증서로 서명·공증하지 않았습니다. 처음 열 때 macOS가 경고를 띄우는데, 아래 순서대로 한 번만 허용하면 됩니다.

## 지원 환경
- **macOS 12 Monterey 이상**, **Apple Silicon(M1~M4)** Mac
  - macOS 12부터 기본으로 들어 있는 OpenSSH 8.6 이상이 필요합니다. 앱이 `/usr/bin/ssh`를 그대로 씁니다.
  - Intel Mac용 빌드는 아직 만들지 않습니다. 필요하면 요청해 주세요.

## 설치
1. GitHub 저장소의 **Releases**에서 `DHost_<버전>_aarch64.dmg`를 내려받습니다.
2. (선택) 같은 Release의 `SHA256SUMS.txt`와 비교해 파일이 손상되지 않았는지 확인합니다.
   ```bash
   shasum -a 256 ~/Downloads/DHost_*_aarch64.dmg
   ```
3. `.dmg`를 열고 **DHost**를 **응용 프로그램(Applications)** 폴더로 끌어 놓습니다.

## 처음 열 때 경고 허용 (처음 설치할 때 한 번)

### "손상되었기 때문에 열 수 없습니다"가 뜰 때 (최신 macOS에서 대부분 이 경우)
파일이 실제로 망가진 것이 아닙니다. 브라우저로 내려받으면 macOS가 앱에 "인터넷에서 받은 파일" 표시(격리 속성)를 붙이는데, Apple 인증서로 서명하지 않은 앱에 이 표시가 있으면 이렇게 나옵니다. 이 경우 시스템 설정의 **그래도 열기** 버튼이 나오지 않을 수 있습니다.

1. 경고 창에서 **휴지통으로 이동하지 말고 취소**를 누릅니다.
2. 터미널을 열고 아래 명령을 실행합니다. **팀 Release에서 받은 DHost에만** 쓰세요.
   ```bash
   xattr -dr com.apple.quarantine /Applications/DHost.app
   ```
3. 응용 프로그램 폴더에서 DHost를 다시 엽니다.

### "Apple은 악성 코드가 없음을 확인할 수 없습니다"가 뜰 때
- macOS 15 Sequoia 이상: 창에서 **완료**를 누르고 **시스템 설정 → 개인정보 보호 및 보안** 아래쪽 "DHost이(가) 차단되었습니다" 옆의 **그래도 열기** → Mac 암호 입력 → **열기**
- macOS 12 ~ 14: 응용 프로그램 폴더에서 DHost를 **Control+클릭(오른쪽 클릭) → 열기** → 경고 창에서 다시 **열기**
- 위 버튼이 보이지 않으면 바로 위 터미널 명령을 쓰면 됩니다.

이 과정은 **처음 설치할 때만** 필요합니다. 그 뒤 앱 안에서 받는 업데이트에는 이 표시가 붙지 않습니다.

## 업데이트
**앱 안에서 업데이트합니다.** (0.1.0 이상)
1. 새 버전이 나오면 앱 아래쪽 상태 표시줄에 **새 버전 x.y.z 업데이트** 버튼이 나타납니다. 앱을 열 때와 그 뒤 6시간마다 확인합니다. **설정 → 앱 업데이트 → 업데이트 확인**으로 바로 확인할 수도 있습니다.
2. 버튼을 누르면 변경 내용이 보입니다. **업데이트하고 다시 시작**을 누르면 내려받아 설치하고 앱이 다시 열립니다.
   - 열린 세션은 끊기므로 작업을 먼저 마무리하세요.
   - 내려받은 파일은 앱에 들어 있는 공개키로 서명을 확인한 뒤에만 설치됩니다.
3. 서버 목록·설정·신뢰한 호스트 키(`~/Library/Application Support/io.github.dongh94.dhost/`)와 저장한 비밀번호(키체인)는 그대로 남습니다.

참고
- 업데이트 후 비밀번호를 저장해 둔 서버에 처음 접속하면 "DHost이(가) 키체인에 저장된 기밀 정보를 사용하려고 합니다" 창이 뜰 수 있습니다. Apple 인증서로 서명하지 않은 앱은 버전이 바뀌면 macOS가 다른 앱으로 보기 때문입니다. Mac 로그인 암호를 넣고 **항상 허용**을 누르세요.
- 앱 안 업데이트가 안 되면(네트워크 차단 등) Releases에서 새 `.dmg`를 받아 응용 프로그램 폴더에 덮어 설치해도 됩니다.

## 지우기
1. 응용 프로그램 폴더에서 DHost를 휴지통으로 옮깁니다.
2. 데이터까지 지우려면 `~/Library/Application Support/io.github.dongh94.dhost/` 폴더를 지웁니다.
3. 저장한 비밀번호는 **키체인 접근** 앱에서 `io.github.dongh94.dhost`를 검색해 지웁니다.
